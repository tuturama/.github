# { tuturama }

**An AI-native software factory for systems that cannot break.**

We build products, embed with security teams inside large institutions, and contribute to the code the world runs on. An Estonian company in the European Union, operating from Tallinn and Lisbon.

- **Products**: [Skywave](https://play.google.com/store/apps/details?id=app.skywave.android), [Listening Robots](https://listeningrobots.com), [Ulpiano](https://ulpiano.tuturama.com)
- **Upstream**: contributions merged into the Linux kernel, Stellar, FediMint, Rig, Foundry and x402, each through the maintainers' review. Live state under [@gabrielrondon](https://github.com/gabrielrondon)
- **Now**: security for AI agents. Threat models for agentic spend, gates in agent tooling, guards for autonomous payments
